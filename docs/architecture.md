# NetworkTrace Architecture

Layers:
1. Data layer — synthetic/anonymized CSV.
2. Graph layer — NetworkX graph construction.
3. Analytics layer — communities, centrality, anomaly signals, temporal statistics.
4. Simulation layer — What-If node removal.
5. API layer — FastAPI REST endpoints.
6. Presentation layer — React dashboard.

The platform should be used for educational network analysis. It must not be treated as a system that establishes criminal responsibility.
