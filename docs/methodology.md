# Methodology

1. Validate and normalize relationship records.
2. Build an undirected weighted graph.
3. Detect communities using Louvain.
4. Calculate centrality measures.
5. Create structural features for anomaly detection.
6. Apply Isolation Forest to identify unusual graph-structure signals.
7. Filter records by timestamp for temporal analysis.
8. Simulate node removal and compare network-level metrics.
9. Present results through a REST API and dashboard.
